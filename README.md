# Supply-Chain-Performance-Dashboard
A comprehensive Power BI dashboard that analyzes supply chain operations, tracking delivery performance, product analytics, and regional metrics to help operations teams identify bottlenecks and improve efficiency.



🛠️ Tech Stack
| Technology | Usage |
|------|---------|
| Power BI Desktop | Data visualization & dashboard creation |   
| Power Query (M) | Data cleaning & transformation |
| DAX | Calculated measures & KPIs |



📊 Data Source
Dataset: DataCo Smart Supply Chain Dataset
Source: Kaggle

| Attribute |	Details |
|------|---------|
| Records | 180,000+ orders |
| Time Period |	2015-2018 |
| Key Fields |	Orders, Products, Shipping, Customers, Geography |



✨ Features / Highlights
Business Problem
Supply chain operations lack visibility into:

- Delivery delays and their root causes
- Product performance across categories
- Regional efficiency variations
- Real-time KPI tracking for decision-making


Goal of the Dashboard
Create an interactive analytics solution that:

- Monitors on-time delivery rates across regions and shipping modes
- Identifies underperforming products and categories
- Provides geographic insights for logistics optimization
- Enables drill-down analysis for root cause investigation



Walk-through of Key Visuals
| Page |	Key Visuals |	Purpose |
|------|---------|---------|
| Executive Summary |	KPI cards, revenue trend line, segment donut chart |	High-level performance overview |
| Delivery Performance |	OTD gauge, delay histogram, shipping mode comparison |	Identify delivery issues |
| Product Analysis |	Category treemap, top products bar chart, ABC matrix |	Product portfolio insights |
| Geographic View |	Interactive map, regional bar chart |	Location-based analysis |
